#### 方法论

- 写文SOP：挖经历 → 找痛点一句话 → 对标爆款结构 → 写草稿 → 检查三问 → 发
- 检查三问：① 一句话能说清痛点吗？② 每段都指向痛点吗？③ 结尾是画面还是说服？
- 钩子公式：痛点/反常识/感受开头，不从事件开始
- 结尾公式：画面或态度，不说服
