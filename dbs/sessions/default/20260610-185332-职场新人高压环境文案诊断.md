## 用户主诉

写小红书文案，选题是「职场新人在高压环境——环境不适合成长怎么办」。已经挖掘了表层事实、具体困境、深层焦虑，需要帮忙看洞察够不够锐利、故事怎么讲更有代入感、方法怎么具体。

## 已得出的结论

- 核心洞察锐利：「不要丢失自己对自己的判断」——四位专家（阿德勒、芒格、李笑来、费曼）都认可这是有价值的核心观点
- 芒格视角的三句犀利洞察可用：
  1. 有些工作经验是负资产，学会被糟糕的人对待而不崩溃是创伤不是经验
  2. 最大风险不是离职，是在错误地方待太久，把别人判断内化成自己判断
  3. 承认招错了人比承认培养不了人更容易——新人可能是被牺牲的样本
- 阿德勒视角：「你留在这里是为了逃避使用你的判断」——不是为了验证判断
- 文案类型确定为：故事+方法型（而非纯洞察型）
- 方法框架：
  - 判断信号：有没有在"变小"（不敢提问、只看脸色、放弃判断）
  - 监控动作：记录"发生了什么、我怎么处理的、我觉得对不对"
  - 止损线：给环境3个月，给自己一个期限

```
【认知转折】为什么你分辨不了？
→ 因为糟糕的环境就是在让你怀疑自己
→ "承认招错了人比承认我们培养不了人更容易"——你不是在成长，你是被牺牲的样本

【核心洞察】
→ "最大的风险不是离职，是在错误的地方待太久，把别人的判断内化成自己的判断"

【方法】怎么知道自己该不该走？
→ 3个信号：你有没有在"变小"
→ 1个监控动作：记录"发生了什么，我怎么处理的，我觉得对不对"
→ 1个止损线：给环境3个月，给自己一个期限

【结尾】
→ 你不需要先证明"不是我的问题"，才有资格离开
```

### 标题方向

- "入职三个月，我终于承认：不是我不够好，是这个环境不需要我变好"
- "那些让你'变小'的工作，正在偷走你对自己的判断"
- "当领导说'你思考太慢'时，他真正想说的是什么"

### 阿德勒"逃避使用判断"的解释

你已经有了判断（"这个环境不适合我"），但你没有行动。因为你害怕使用自己的判断后要承担责任（比如离职后找不到工作）。所以你选择"留在这里证明是环境的问题"——这样你就可以继续待着，不用做决定。"逃避使用它"的意思是：你用"我不知道"来逃避"我知道但我不敢"。
