## 用户主诉

系统学习小红书用户心理和内容代入的方法论，掌握持续产出好内容的系统。

## 已得出的结论

- 用户形成了完整的内容产出 SOP：挖掘困境 → 确认困境 → 确定方向 → 聊清楚 → 大白话写 → 诊断 → 完善
- 掌握了三层追问方法：表层事实 → 具体困境 → 深层焦虑 → 隐藏规则
- 掌握了三个内容方向：洞察型（让用户看见没看到的规则）、故事型（分享经历和尝试）、方法型（给具体做法），可两两叠加
- 理解了困境是内容的起点，困境从搜索词、评论区、自己经历、对话、对标中来，不是"想"出来的
- 建立了困境库的概念和结构：原始记录区 → 已挖掘区 → 已写区
- 风格需要在大量写和觉察中自然形成，不是设计出来的
- 大白话写 + 保留粗糙感 = 真实感
